# agentx experiment

This directory is an interactive experiment explicitly retained for the user to inspect.
Read [README](README.md) and the bound [task](task.md). Follow the project guidance.

Keep your work inside this directory. Edit task state directly in its original frontmatter;
preserve unrelated metadata and Markdown. agentx only reads this task and has no task-write commands.
Use the Session identity supplied by agentx; query agentx for runtime state.
Create the requested runnable example, with verification results in task progress.
Do not create reports, logs, lock files, extra tasks or runtime-history files.
After recording initial progress in the task, mark it blocked for user input and end your turn so the
user can inspect the waiting state and continue through agentx. Keep the agent available.
