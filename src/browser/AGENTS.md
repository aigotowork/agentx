# Shared browser mechanics

This module owns only manifest/byte bounds, strict JSON parsing, lossless integer JSON and HTTP framing and credential-free open-origin CORS shared by diagnostics, collaboration and management. Management uses `decode_json` with native string IDs; diagnostic/collaboration codecs retain their integer marker format. Product authority, fixed scope, route mapping, service semantics and embedding-table selection stay in the owning adapters. Preserve diagnostic behavior and cases when moving shared functions. Read the [native Task](../../.controller/collaboration-workbench/tasks/collaboration-service.md) for current source/execution boundaries. Current browser policy and platform limits are maintained in [the HTTP projection guide](../../.docs/api-panorama/openapi/README.md#browser-access-policy); [the active native Task](../../.controller/web-sdk-adoption/http.task.md) owns source/acceptance status. `admission.rs` owns syntactic Host/target checks, side-effect-free preflight and response headers shared by all three listeners. Host/Origin/Fetch Metadata never select scope or native authority. Tests exercising moved mechanics remain in `../observability/web/tests.rs`; management adds independent [public cases](../../tests/agent_management/AGENTS.md). Independent acceptance executes them.

`openapi.rs` owns pure projection mechanics shared by the three SDK surfaces: typed HTTP error/empty envelopes, actual native-integer-schema → `$integer` wire-object mapping, and offline export dispatch. Keep `x-agentx-native-integer` sign/width metadata tied to the source schema so SDK bigint mapping can enforce bounds; do not rewrite identity strings or native serde. Management keeps ordinary v1 JSON numbers. This projection does not grant authority, acquire scopes or start daemons. Listener path/operation/result policy stays in each listener's own OpenAPI module and actual annotated binding functions.
