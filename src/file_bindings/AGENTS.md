# File-backed Task/Delivery bindings

Read [usage and exact semantics](../../.docs/file-task-bindings.md) and [implementation Task](../../.controller/file-task-bindings/task.md). `document.rs` owns YAML/frontmatter semantics and exact file assignments, `write.rs` owns locked preserving writes and compensating rollback, `index.rs` owns bounded discovery and disposable observations. Runtime prepares bounded file snapshots for supported tools' initial task messages before reservation and calls the binder after exact native reservation, before process creation. The [binding projection worker](../service/read_application/bindings.rs) owns the index and file reads; the daemon reader uses published views keyed by exact assignment. Files are the only authoritative binding state. Never infer exact assignment from a reusable name or document completion from runtime status.
