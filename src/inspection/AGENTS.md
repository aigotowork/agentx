# Native inspection

Read [live model](../../.docs/inspector/live-model.md) and [Task](../../.controller/live-ui-integration/tasks/native.md). `contract.rs` owns native declarations; `store.rs` owns daemon transactions and KV retention; `collection.rs` maps originating Provider reads without database access; `analysis.rs` owns deterministic summaries; `recovery.rs` owns exact episode guards. Integration owns root/service/HTTP/generated TS and worker startup. Never expose internal collection admission directly to browsers. Keep source paths private, exact AgentRef/generation/revision, coverage gaps, unknown usage and once-per-episode recovery barriers. This module does not call paid Providers or perform PTY/process effects.

## Public management consumer

`contract.rs::PublicMutation` is the closed four-POST input; its shared ConfigureInput/AnalyzeInput/CancelAnalysisInput/RequestContinuationInput payloads also construct the native Request variants with identical externally tagged serde. Keep Read as a dedicated snapshot operation and Collect/RunAnalysis private to native runtime supply. Do not publish the whole Request/Response enum as browser authority. `management/service/inspection.rs` binds public calls to the existing fenced Client and returns Snapshot/AnalysisJob/RecoveryAttempt directly; store/recovery/collection keep their original policy and lifetime.

Native public-payload newtype refactoring changes Rust constructors but preserves serialized IPC/HTTP JSON; do not rotate protocol/storage versions solely for this source refactor. `management/service/tests.rs::inspector_public_tags_round_trip_native_payloads_and_refuse_internal_variants` protects the four public/native wire pairs and private exclusions. Existing store tests protect configure revision, collection gaps, analysis and episode recovery. The [full-native Task](../../.controller/contract-service-projections/tasks/full-native.task.md) owns actual execution/consumer integration evidence. This extension does not authorize paid Provider requests, PTY/process effects or installed/live adoption.
