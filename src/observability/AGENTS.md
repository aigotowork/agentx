# Native observation capability

For Hook invocation timing, capture family correlation, offline trace reads and admission pressure changes, follow [telemetry coverage](../../.docs/observability/telemetry-coverage.md) and [the current task](../../.controller/observability/telemetry-optimization.task.md). `trace.rs` owns local bounded capture and selection; `runtime.rs` owns native request lookup and metrics.

Read the [current feature](../../.docs/observability/README.md), [engineering map](../../.docs/observability/engineering.md), [implementation team](../../.controller/observability/implementation-team.md) and your original implementation Task before changes. Native declarations own exact implemented contracts. The design acceptance is source/semantic evidence, not executable observation support; independent [native integration](../../.controller/observability/implementation-tasks/native-integration.md) owns current execution evidence.

| Responsibility | Native authority and permitted change |
| --- | --- |
| Shared scope/daemon/dataset/clock/evidence | `context.rs`; pure shape validation, no scope creation, storage, authentication or business authority. |
| Public module exports and shared architectural conflicts | `mod.rs` and native-contract Task owner; coordinate actual exports once, not per-line approval queues. |
| Runtime requests, registry and origin reports | `runtime.rs` public contract; `registry.rs` private bounded implementation; runtime owner. |
| Immutable configuration capture, disclosure and comparison | `configuration.rs` public contract; `configuration_store.rs` private bounded implementation; configuration owner. |
| Event sink, ordered stream, loss and retention | `events.rs` public contract; `journal.rs` private bounded implementation; events owner. |
| Passive endpoint, accepted peer, insertion sites and epoch publication | `../daemon/observation.rs` and existing source composition; dedicated composition owner. |
| Credential-free local/LAN browser transport and finite read mapping | [Adapter guide](web/AGENTS.md), [HTTP contract](../../.docs/observability/browser-api.md) and [browser bindings guide](../../web/observability/api/AGENTS.md); adapter owner, separate from native domain policy. |

Public leaf contracts can import sibling public values when their actual meaning matches. Do not import another owner's private store, managed SQLite, daemon internals, CLI parser, Provider frame or browser framework into observation policy. Existing native participant/message/receipt/host rules retain authority. Domain contracts expose constructors/reader/producer handles; composition selects and supplies them.

Create one `ObservationClock` at daemon composition and pass clones to each store. Originating clients retain their own clock; compare monotonic values only when ClockIds match. Unknown generation permits process diagnostics via DaemonRef and never an empty ObservationEpoch. Only the application/durable key owns generation; reset rotates projections after its committed publication. Same-epoch replacement cannot recycle an existing reference.

Diagnostic facts cannot change business outcomes or authorize effects/replay. Keep observation writes bounded and nonblocking where the offering requires it; no storage, Provider, transport I/O or resolver runs while holding a store lock. Export only safe fields; assess combined records so token/receipt material cannot be reconstructed. Inspection and report infrastructure does not recursively instrument itself.

When promoting a design declaration, replace its Markdown copy with a native source link and retain the semantic explanation. Update the feature route/guide only where ownership changed. Author meaningful owner-local cases and report them unexecuted; the named integration owner alone runs current formatters/builds/tests/probes. Current Task metadata owns work state; no new support claim follows from a module declaration or test authorship.

## Configuration evidence maintenance

Use [`configuration.rs`](configuration.rs) for exact capture references, stages, field policies, report/inspection enums, required resolver port, local capture handle and pure comparison. [`configuration_store.rs`](configuration_store.rs) is private immutable FIFO retention; composition imports its `ConfigurationStore` re-export through the public configuration leaf. The [configuration model](../../.docs/observability/configuration.md) owns semantic rules and the [configuration implementation Task](../../.controller/observability/implementation-tasks/configuration.md) records the scoped release and evidence limit.

The actual settings resolver remains `AgentxConfig::load_for_scope_observed` in `../config.rs`. Its `../config/observation.rs` adapter records the same parser/selection/coercion/validation decisions; missing trace stays unknown. Never run the resolver from a retained read or reconstruct a historical snapshot from current files. `project_effective_config` reads only policy-approved effective values and consumes the supplied trace. A launch plan, validated host report and participant projection use their own typed subject/stage/purpose and actual owning boundary.

Construct one configuration store per daemon lifetime with the shared daemon clock; clone its handles. `rotate_epoch` preserves same-era allocation/frontier and only an actual new epoch clears overflow; a fresh constructor cannot replace that allocator in the same daemon/era. Reads and publication check the epoch while holding the same store lock. Publication/event callbacks occur after releasing store/business locks. Nonblocking skip counters can be incomplete under contention; the returned capture disposition remains explicit.

An originating `InvocationCaptureHandle` shares revision allocation and local retention across clones; `revise` allocates a distinct immutable revision. Local snapshots are invocation/launch-plan claims, never daemon/host authority. Generic reports bind the actual transport `AcceptedPeer`; validated host intake is a separate in-process port. Hidden value equality remains unknown, credentials have fixed withheld value/provenance, and no environment map, raw candidate/error, argv, token or secret fingerprint is retained.

Owner-authored scenarios live in [`configuration_tests.rs`](configuration_tests.rs) and [`configuration_store_tests.rs`](configuration_store_tests.rs), with filters `observability::configuration::tests::` and `observability::configuration_store::tests::`. They cover real loader traces, immutable file-edit history, redaction, cloned revisions, FIFO/count/byte/age pressure, peer quotas, finite facade/error branches and concurrent epoch changes. Authoring is not execution; the assigned independent native integration owner records the current candidate and results.

## Events maintenance

Consume `events::{ObservationJournal, ObservationReader, ObservationSink}` through the public Events leaf; `journal.rs` remains private. Exact declarations, validation and limits live in `events.rs`; cursor, fence, retention and evidence meaning lives in the [event model](../../.docs/observability/events.md). The [original implementation Task](../../.controller/observability/implementation-tasks/events.md#composition-mapping-and-lifecycle-handoff) owns producer mapping and current evidence.

Composition is the sole lifecycle writer. Construct the journal with the actual lease daemon and shared clock; publish only a committed epoch. Before changing the generation mirror, withdraw the old journal, then publish the new epoch and replace producer handles. A sink is fixed to one epoch/nonce and holds a weak journal reference; it never redirects late work or pins retired record buffers. Prune on the bounded daemon tick, including idle periods, and close before lease release. Counter/sequence exhaustion requires explicit same-epoch replacement and fresh handles. A poisoned collector is unavailable, not retryable contention; close is terminal.

Capture only safe reference projections using the existing nested transaction/savepoint budget; flush after outer commit and outside SQLite. Rollback discards prepared projections. `MessageAccepted` is distinct from generic `EventAppended` and carries the actual native acceptance request/event refs plus replay status. Output confirmation uses fresh `OutputObservationId::new()`, never native token IDs; delivery confirmation keeps only exact claim and safe boundary/disposition. Never copy raw bodies, receipt frontier/turn IDs, environment or error text into telemetry. Runtime's restricted intake supplies current authenticated `AcceptedPeer` separately from historical client claims.

Keep successful append sequences contiguous. Pre-sequence drops and retained-prefix gaps have different meaning. Read windows preserve their original through/filter; `next.after` is the scanned frontier and cannot pass a byte-blocked matching record. Keep era checks ahead of numeric bounds. Observation/report infrastructure is suppressed rather than recursively recorded. Meaningful owner cases live in `journal_tests.rs` (`observability::journal::tests`); independent native integration executes them together with actual rollback, lost-reply, reset and passive-lane wiring cases.

## Runtime maintenance

The runtime public capability is `runtime.rs`, which re-exports RuntimeRegistry and its RAII guards from private `registry.rs`. Runtime transitions preserve execution, reply-wait and reply-write separately. Queue insertion uses `publish_queued` around native nonblocking try_send; dispatcher callbacks pass the same short gate before applying dequeue/dispatch. WorkerFinished releases only the worker pin, while Application return/rejection releases the dispatcher pin. Never reclaim a request while either can still change it.

Composition supplies one ObservationClock. Registry generation publication resets only the current-era window and dataset host interpretation; lifetime counters and explicitly labeled process chronology remain. Request event input retains its original generation and a late producer cannot be relabeled through a replacement event sink. Transport binds AcceptedPeer separately from client body claims. Inspection resource guards allocate accepted connection refs without recursively generating business telemetry.

LocalFailure permits unavailable capture time. Preserve an independently known cause/stage/OS code with at=None; the clock facility itself uses ClockUnavailable with no timestamp or OS code. None proves no ordering or age. Never fabricate sentinel time or a fresh clock to return an error or admit a report; report start/end/span clocks remain required.

Runtime rows/metrics are finite; readers use try_lock and return Busy/Unavailable honestly. Capped encoded-size counting may run during a bounded transition to enforce retained byte limits, with no serialized output allocation or external I/O. Event and complete response serialization happen after unlocking. `registry_tests.rs` owns state/pressure/reuse/reset/report cases; the native integration Task owns executable evidence and real endpoint saturation/isolation.

The user-selected [direct LAN and standalone follow-up](../../.controller/observability/lan-usability.md) supersedes historical browser bootstrap/session/external-bundle requirements. Use the current [browser contract](../../.docs/observability/browser-api.md); native daemon authentication and safe finite read policy remain unchanged.
