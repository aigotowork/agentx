# Actual consumer cases

Read the [original diagnostics Task](../../../../.controller/observability/implementation-tasks/diagnostics.md), [native integration Task](../../../../.controller/observability/implementation-tasks/native-integration.md) and [source grammar](args.rs). These are authored, unexecuted process scenarios for the existing independent fixture owner. They complement the 21 owner-local [cases](tests.rs) and five existing [artifact families](../../../../tests/observability_cli.py); they are not another runner, mock backend or evidence receipt. Integration executes only on the released fixed candidate in its explicit disposable HOME/AGENTX_DIR/XDG roots and owns all exact child/endpoint cleanup.

| Case | Actual entry and deciding setup | Required observable outcome |
| --- | --- | --- |
| CLI-01 / OBS-01,06 | Existing artifact families: missing-scope, existing-scope-without-daemon, scope-is-file, relative-alias, malformed-reference-files. | Preserve their actual `result.LocalFailure`, `scope.Existing`, lexical requested path, Probe/DiscoveryOnly report and unchanged scope tree assertions. Exercise normal worker/queue saturation separately using the existing native fixture's exact handles. | Actual passive output arrives while the dispatcher remains held. Request execution/reply/configuration dimensions remain native. Complete/abandon the ordinary call through its existing fixture, and retain actual product result separately; observer exit never becomes effect confirmation. |
| CLI-03 / OBS-04 | On the actual isolated daemon, generate two native application configuration captures using two originating environments in the same scope. Obtain exact Recorded refs from actual request details when retained. If the native request-detail byte cap drops a detail, require explicit runtime `coverage.request_details_dropped` evidence for that loss and obtain exact native refs from `Configuration.SnapshotPublished` events correlated to each same originating attempt; preserve their scope/epoch and correlation evidence. | CLI-04 / OBS-05,08,09 | Generate actual journal records and run `observe events --limit 1 --scope S --json`. Save complete returned Page.next to FILE.
