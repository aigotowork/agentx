# Management token source

[Management styles](../web/management/styles/management.css) define the cool neutral and cobalt palette, semantic statuses, sans and mono typography, spacing and base focus. [Interaction styles](../web/management/styles/interaction.css) consume those roles and own tactile feedback, dialog depth, timing, and reduced motion for the refined shell, conversation and receipts. Light and dark map the same semantic roles. Reserve elevation for floating surfaces. Do not copy the token values into this index.
