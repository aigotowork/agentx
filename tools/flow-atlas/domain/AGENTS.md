Use `bindNativeMethod` with imported native input/output SchemaHandles and actual method/prototype values. Never instantiate a receiver to inspect a method. Portable operations strip the handle and retain only `nativeMethodId` and `nativeOutputSchemaId`; source links alone stay declared. Native method signatures are typechecked against schemas, while outcome projection and source-body correspondence remain explicit, not inferred proof. There is no method invocation API on this binding layer.
