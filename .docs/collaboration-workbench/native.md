# Native contract release

The [actual declarations](../../src/collaboration/service.rs), [browser closure](../../src/collaboration/web/api.rs) and [owning module](../../src/collaboration/AGENTS.md) replace the capability document's callable sketches. Aggregate rules, daemon composition, SQL persistence, native CLI and HTTP adapters are source-authored; this source owner authored [cases](../../src/collaboration/cases.md) without executing them. The [original Task](../../.controller/collaboration-workbench/tasks/collaboration-service.md) owns source release; [independent evidence](../../.controller/collaboration-workbench/evidence/acceptance.md) owns executed checks and the support scope below.

`Request::Read` returns finite project work/candidates/detail/command receipts and safe paged thread messages through the existing Events query capability. WorkDetail contains the bounded complete structured aggregate; Thread is separately paged ordinary native conversation. `Request::Apply` separates `OperatorCommand` from exact actor-bound `AgentReport`. All references carry canonical scope, project, generation and ID. Revisions are lossless integers. String command IDs are 1–96 ASCII alphanumeric/hyphen/underscore; use UUIDs. Receipts preserve the original small `Change`, not a second copy of the aggregate. Replay compares exact normalized intent and actor before checking current revision. Missing lookup is unknown, not proof a disconnected request failed.

Limits are 8192 UTF-8 bytes per text, 240 title bytes, 2048 source-reference bytes, 256 source-revision bytes, 32 criteria/artifacts, 256 total retained history entries and commands per work, 1 MiB serialized aggregate, 512 works per generation and 64 list/thread rows per page. Thread projection has a 1 MiB page budget; optional continuation points at its last emitted native event. At least one criterion is required. Result source identity must be a full 40/64-hex Git object ID or `sha256:` plus 64 hex digits, distinct from an original brief's retained source/revision metadata. Relative artifact paths reject absolute/traversing/platform-escape forms; source/artifact bytes are not fetched. A capacity denial rolls back both native admission and aggregate/receipt. Histories are retained, never silently evicted. Additive schema v23 retains daemon-owned `collaboration_work` and `collaboration_commands` tables and clears them on managed reset; accepted records remain readable and closed.

The browser descriptor supplies fixed scope/project/mode, generation/service availability and native limits. Closed HTTP routes are POST `/api/v1/connection`, `/api/v1/read`, `/api/v1/apply`; readonly launch rejects apply. Native reporting is absent from the browser closure. Integer markers, syntactic HTTP framing, no-store/CSP and finite resource limits reuse `src/browser` without changing diagnostic routes/policy. HTTP bodies are <=512 KiB and replies <=2 MiB, with eight connections/native calls, bounded body/header/connection timeouts and [credential-free open-origin CORS/iframe support](../api-panorama/openapi/README.md#browser-access-policy). A disconnected possible native write returns OutcomeUnknown and retains its command identity. Startup prints the listener URL only; Ctrl-C closes only this adapter. Local launch acquires the selected native daemon; HTTP cannot start or select a different scope, and explicit daemon restart remains a separate native operation.

## Workbench startup and defaults

在项目目录使用 `agentx workbench` 即可打开嵌入式工作台：scope 默认遵循当前 `AGENTX_DIR`，未设置时使用正常 home scope；project 默认是调用时的工作目录。需要有限协作写操作时显式加 `--collaboration`。`--scope PATH`、`--project PATH` 分别覆盖默认值，相对路径以调用目录为基准。项目必须存在，缺失的 scope/守护进程会在本地启动阶段正常获取，不需要先运行 `daemon serve`。这些启动值不从配置文件另行读取。

本地只读和协作模式都会获取服务，随后 HTTP 只能连接同一 canonical scope 中已存在的服务。浏览器不能改变 scope/project 或自动启动服务，`--collaboration` 只决定有限写入权限；被动 `observe`/`observe-web` 保持原有不启动服务语义。构建不匹配会保留实际兼容诊断和可执行的 `daemon restart --scope` 恢复命令；工作台不会自行终止旧进程。默认监听 `127.0.0.1` 的系统分配端口，`--host`、`--port` 和 `--assets` 仍可显式覆盖。启动成功输出一个 URL；错误写 stderr 并返回 1，用法错误返回 2，帮助返回 0。

[`web/mod.rs`](../../src/collaboration/web/mod.rs) 是启动契约，路径默认/显式覆盖和原有 HTTP 模式拒绝用例位于同目录 `tests.rs`。本次启动修订的实际支持以[独立启动证据](../../.controller/domain-daemon/startup-evidence.md)为准；下文历史工作台验收不自动验证本次默认值和恢复行为。

Agent report grammar: `agentx work report --scope PATH --project PATH --work ID --generation GEN --revision N --assignment ID --brief N --command-id UUID --payload JSON [--iam NAME]`. Payload is one native `AgentReport` serde value, e.g. `{"Progress":{"kind":"Acknowledged","summary":"Received"}}`, `{"Question":{"prompt":"Overwrite?","suggestions":[]}}`, `{"Result":{"summary":"...","source":{"reference":"git","revision":"COMMIT"},"artifacts":[{"Git":{"revision":"COMMIT","path":"src/export.rs"}}]}}`. Check payload is native `CheckInput` under `Check`. `--iam` selects an existing participant under the native resolver's local-user authority; the daemon compares exact current assignment/incarnation/basis. This selection and its receipt do not independently authenticate a Provider process as the author. The existing Participants resolver owns Provider/session/process binding semantics. No browser client may claim a report actor.

Every required message is composed through existing messaging admission under the same outer write scope. A retained acceptance means queued message, not delivered/started/completed. Positive delivery is not fabricated; initial work message projection retains admission only and displays delivery unknown. Report/check evidence is attributed to its exact participant; acceptance is an explicit credential-free operator statement without authenticated personal identity.

## Everyday entry and native reads

`agentx workbench --scope PATH --project PATH --collaboration --host 127.0.0.1 --port 0` explicitly acquires the selected daemon at local startup and serves embedded fresh resources. Omit `--collaboration` for finite reads; local startup still acquires once and HTTP never starts a daemon. Scope/project may be omitted as described in [startup defaults](#workbench-startup-and-defaults). Numeric LAN interfaces and an explicit nonprivileged port use the same entry. There is no login/token/bootstrap stage. Existing `observe-web` remains its separate passive diagnostic host.

`agentx work show --scope PATH --project PATH --work ID [--generation GEN]` reads the current authoritative revision, assignment IDs, dispatched brief, result/check requests and eligibility. `work list` and `work candidates` accept `--limit`/`--after`; `work command --generation GEN --command-id UUID` reconciles a retained command. Native CLI prints serde JSON with ordinary exact integers (use an integer-safe parser); browser wire uses markers. Native rejected operations print `Rejected` and exit 2; acquisition/transport failures go to stderr and exit 1; success exits 0. Lost report replies are never automatically replayed.

`work apply --scope PATH --project PATH --generation GEN --command-id UUID --payload OPERATOR_COMMAND_JSON [--work ID --revision N]` offers the same finite operator commands for local callers/fixtures. Creation omits work/revision. These commands select no generic shell/SQL/file/lifecycle capability. Their native domain guards are shared with the browser. Participant candidates are exact local rows whose stored canonical directory matches the selected project; inactive/stopped/killed and remote rows are unavailable. Busy alone does not disqualify a participant. Stored status is not a positive liveness or delivery proof.

## Source structure and receiving limits

The [Work methods](../../src/collaboration/model.rs) own transition/eligibility rules; the [daemon adapter](../../src/collaboration/store.rs) owns actor/participant fences, replay/transaction/effect composition and safe reads. [Persistence](../../src/db/collaboration.rs) owns only SQL. Shared browser helpers preserve their original diagnostic cases and finite manifest format `{files:[{url,file,content_type}]}`; each app selects its own generated tuple expression. Web owns `OUT_DIR/workbench_assets.rs` generation and Native consumes it. No production source invokes another CLI or Provider while holding a write scope.

The [independent acceptance Task](../../.controller/collaboration-workbench/tasks/acceptance.md) owns compilation, formatter/lint/test, locked install, real Provider/browser outcome and standalone binary evidence. The [storage model](../model/storage-boundary.md#dedicated-daemon-adapters) records the exact borrowed adapter and schema/reset boundary; no constructor or client fallback permission follows from that placement.
