# Runtime atlas

Read root guidance and [shared interface standard](../../../.agent-guides/scenarios/interface-design.md). [README](README.md) owns schema/source/evidence routes; [Delivery](../../../.controller/domain-daemon/runtime-atlas.md) owns completion.

This is an explanatory model and standalone HTML projection, not a runtime client. Never read `.agentx`, call product APIs, launch Providers or signal processes. `model.json` owns AgentX semantics; shared [Flow Atlas](../../../tools/flow-atlas/AGENTS.md) owns the reusable core and sole viewer source, local `build.py` validates repository provenance and generates `index.html`; never edit generated output. Distinguish processes, contained modules, stores and logical threads. Disconnect alone cannot establish native thread termination. Preserve compact selection/context and keyboard/touch access. Controller owns execution during delegated authoring; no package install/Cargo rebuild/live-service change is needed.

Visible execution consumes authored `step.beats` and runs `ready → flow → handling → applied`. Keep the previous snapshot until application, animate only declared transport/direction, and preserve disconnect/local/unknown meanings. Pause freezes elapsed presentation time; reset/back/mode/scenario/hash cancel obsolete frames. Keep the graph primary, with compact event/fact controls and one dismissible disclosure layer. Browser acceptance must observe motion and staged changes under normal motion, not only text under reduced motion; use the cases and actual evidence linked by README.

All three projections share one trace/checkpoint/transition. Speed scales only elapsed presentation time; paused packet position is stable across rate/view changes. Optional layout hints and fact labels belong to model data, not hardcoded AgentX IDs in generic code. Flow diagrams show the selected authored scenario, not all branches; sequence diagrams project exact authored beats. Runtime support is unchanged by generic tool reuse.

Object ports and interactions follow [the shared contract](../../../tools/flow-atlas/contracts.md) and [accepted outcome](../../../.controller/domain-daemon/tasks/runtime-atlas-ports.md#accepted-object-and-port-outcome). Port labels group source-owned responsibilities rather than inventing native wire methods. Keep message acceptance, Provider input observation and delivery confirmation separate. The old step IDs/initials/patches remain authoritative; interaction effects only reference those changes. Disconnect remains a non-call, and unknown input cannot claim a response or successful change.

The [current canvas outcome](../../../.controller/domain-daemon/tasks/runtime-atlas-ports.md#accepted-canvas-port-and-state-outcome) draws named method pins, exact call links, payload fields and `node.stateFacts` projections directly on the canvas. Keep the latter as references to existing facts, never duplicate values or imply storage ownership. Distinguish hollow caller origins from inbound callable Port dots; reverse response paths exist only when the authored interaction declares them. Generic geometry and rendering live only in shared viewer/canvas.js; lifecycle meaning stays in model.json.
