# Browser adapter contract

The [LAN usability follow-up](../../.controller/observability/lan-usability.md) supersedes the original credential/loopback/external-assets restrictions. The [original adapter Task](../../.controller/observability/implementation-tasks/local-adapter.md) records implementation history; the LAN follow-up owns current execution state and acceptance. This contract extends the selected [consumer boundary](consumer-boundary.md) and links actual [HTTP provider](../../src/observability/web/mod.rs), [closed read declarations](../../src/observability/web/api.rs), [precision codec](../../src/observability/web/wire.rs) and [browser client](../../web/observability/api/client.ts). Native [inspection](../../src/daemon/observation.rs) and leaf contracts remain the sole authority for results, disclosure, eras and evidence. The LAN follow-up records actual direct-access/browser and standalone-resource verification. [Earlier consumer integration](../../.controller/observability/implementation-tasks/consumer-integration.md) retains historical credentialed-consumer evidence and its original limits.

## Launch and asset handoff

`agentx observe-web --scope PATH [--host IP] [--port PORT] [--assets DIRECTORY]` is dispatched before ordinary configuration/identity setup. Scope is mandatory, resolved once as an existing directory. `--iam` is accepted as a shared invocation option and ignored; it never initializes an identity. Host defaults to `127.0.0.1` and accepts numeric IPv4/IPv6; `--host 0.0.0.0` enables LAN IPv4 access. Port defaults to 0 (ephemeral); nonzero must be >=1024. Launch uses embedded compiled resources by default, with `--assets` as a development override. It does not contact/acquire/start a daemon or load client configuration. Stdout prints `http://BOUND_ADDRESS:PORT/` without credentials; when binding a wildcard, visit the machine's actual numeric interface address at that port. Binding establishes adapter readiness, not daemon availability. SIGINT closes the listener, aborts HTTP tasks and waits only for finite native work. Adapter lifetime does not own product lifetime.

Web owns all actual page/assets and produces a bundle directory with `manifest.json`: `{"files":[{"url":"/","file":"index.html","content_type":"text/html; charset=utf-8"},{"url":"/app.js","file":"app.js","content_type":"text/javascript; charset=utf-8"},{"url":"/app.css","file":"app.css","content_type":"text/css; charset=utf-8"}]}`. This is a manifest example, not a supplied page. At most128 files,4MiB per file,16MiB total,32KiB manifest; `/` must be HTML. Allowed MIME types are the three shown plus `image/svg+xml`, `image/png`, `image/webp`, `font/woff2`. Paths must be relative normal components, canonicalize inside the selected bundle and resolve to regular files. URLs use only ASCII alphanumeric plus `/._-`, disallow `..`, duplicates and `/api/`. Bundle bytes are preloaded; HTTP never reads a browser-selected file. Missing/invalid bundle rejects launch instead of serving a fake success page. Web builds its own bundle into a named disposable destination and hands the directory to integration.

Serve all scripts/styles/fonts/images from the bundle origin. CSP permits only same-origin script/style/img/font/connect; inline scripts/styles, workers, frames, objects, forms and external resources are disabled. Every response uses no-store/no-referrer/nosniff and permits iframe embedding under the [shared browser policy](../api-panorama/openapi/README.md#browser-access-policy). The entry script calls `ObservationApi.connect()` to read the launch-selected scope before mounting the investigation. Each visit, reload and browser client connects independently without credentials. There is no bootstrap, bearer, session expiry, logout route, cookie, storage, worker, URL token or telemetry export. `close()` only cancels that page's pending browser reads.


## HTTP operations and origin boundary

All API bodies/responses are UTF-8 JSON. POST requires exact `Content-Type: application/json`, no Content-Encoding; at most32KiB body within2s. The [shared browser access policy](../api-panorama/openapi/README.md#browser-access-policy) permits cross-origin browser Fetch and OPTIONS/preflight without Origin/Fetch Metadata admission or Host-to-socket matching. One syntactically valid Host and origin-form request target remain required; queries remain rejected. No browser PID/environment/actor claims grant native authority.

| Operation | Input | Completed result |
| --- | --- | --- |
| `POST /api/v1/scope` | `{}` | Launch-selected `ScopeRef` directly; repeatable and independent of native daemon availability |
| `POST /api/v1/read` | [ReadCall](../../src/observability/web/api.rs); no credentials | `ReadResult::Inspection(InspectionResult)` or `ReadResult::LocalFailure(LocalFailure)`; native JSON tags preserved |
| Manifest-listed `GET` | Valid Host; no credentials | Actual preloaded bytes/MIME; unlisted URL404 |

Exactly8 accepted HTTP connections maximum,5s header deadline,32 headers/16KiB header-buffer bound,10s maximum connection lifetime, no HTTP keepalive. Excess connections close before parsing. At most8 in-flight native reads across all clients; native transport retains its independent2-worker/1s limits and typed Busy. Event reads share this capacity with other reads; there is no global event poll lock. The client prevents overlapping EventsRead within its own page instance. The semaphore permit remains owned by the actual native read after HTTP cancellation, preventing unbounded disconnected work. No server subscription, cursor pin or automatic polling/retry/rebase exists. Web may schedule a new read after completion at >=1s/backoff and cancels its timer on navigation/hidden/close. Already shown evidence remains historical on disconnect; native daemon loss differs from adapter transport loss.


## Closed native mapping and precision

ReadCall is `{expected_daemon: DaemonRef|null, read: BrowserRead}`. BrowserRead permits only Snapshot, Requests(selection/page), RequestDetail, Connections, Peers, Hosts, ClientReports, ClientReportDetail, ConfigurationHead(expected epoch), ConfigurationLookup, ConfigurationCompare, EventsDescribe, EventsRead. Exact enum payloads live in the native declaration and its derived bindings. All nested supplied scopes must match launch scope; scope operands never change it. Request/config/report detail IDs must be positive. Runtime page limits1..64 (before must be null or positive), event page limits1..256, native field selection/filter validation stays authoritative. Event numeric frontiers are interpreted only by native era-before-frontier rules. Unknown/duplicate JSON fields and native mutation/report variants are rejected before inspection. There is no domain/business/file/environment/read-SQL/re-evaluation/report endpoint. Domain evidence links remain visibly unavailable because no additional domain read with its original prerequisites is selected.

Every native integer (signed or unsigned, counters, PID, IDs, limits, clocks, incarnation bits) becomes a single-key object `{"$integer":"18446744073709551615"}` on HTTP. Canonical decimal only: no leading zeros, `+`, `-0`, floats or exponent. Native strings remain strings; booleans/null/enums/object/array shape stay native. Incoming raw JSON numbers and malformed/extra-key markers are rejected. Domain deserialization enforces each exact integer width. The public `@agentx/client` maps integers to JavaScript bigint and back; [client.ts](../../web/observability/api/client.ts) owns only page connection composition. Never convert refs/time/frontiers to Number. [native.ts](../../web/observability/api/native.ts) now aliases public SDK schema-map types, including complete result/error/stale/gap/coverage/provenance branches. Native Service → emitted OpenAPI → package generation is the maintained chain. Vite bundles the public SDK into the finite native asset manifest. See [SDK adoption](../../.controller/web-sdk-adoption/web.task.md).

Native Result uses `{Ok:...}`/`{Err:...}`, externally tagged enum payloads remain unchanged, unit variants remain strings. Ready, received_at, returned daemon and every native stamp/coverage/loss/error survive mapping. A200 LocalFailure is daemon transport evidence, not adapter failure or an empty successful read. Native inner errors stay inside Inspection. No join claims cross-owner atomicity, no clock subtraction crosses ClockIds and no stale evidence becomes healthy/current by being fetched successfully.

## HTTP rejection and failure contract

Non200 JSON is `{error: CODE}` and never reflects input/error text/secrets.403: WrongHost/WrongOrigin/InvalidTarget.405: MethodNotAllowed.404: NotFound.415: InvalidContentType.413: BodyTooLarge.408: BodyTimeout.400: InvalidInput/ScopeMismatch.The page client alone reports409 PollInFlight for its own overlap guard.503: Busy/AdapterUnavailable/ResponseUnavailable. Complete encoded JSON response cap2MiB accommodates the native512KiB response after integer-marker expansion; excess becomes ResponseUnavailable, never truncation or an invented empty result. A connection rejected before HTTP parsing, cancellation, listener death or network failure has no JSON result; the browser exposes AdapterDisconnected separately. No response reflects arbitrary native error strings. Source cases and independent evidence remain separately attributed.
