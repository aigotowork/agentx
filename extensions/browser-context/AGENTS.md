# Browser context extension

Read [design](design.md), [Chinese usage](README.md), [owned Task](../../.controller/context-clients/extension.md), [canonical bridge](../../.docs/agent-management/web-context.md) and [responsive Space contract](../../.docs/agent-space/responsive-space.md). This is a thin browser host of the same full Space; never recreate member/office/attachment UI or poll native Agent APIs in this wrapper. Keep all behavior dependency-free and within this module. `panel.js` composes service configuration/capture/bridge; no host permission gate or AgentX API polling; background owns toolbar behavior only. Capture gets the child current exact target + opaque selectionRevision before asynchronous browser I/O; existing addContext carries that unchanged fence and result verifies returned identity/revision. Never send File/Blob through Chrome runtime messaging; reconstruct screenshots in iframe parent. Preserve service/document/tab epochs, retained failed capture copy and uncertain-result same-ID recovery. Packaging is deterministic via `package.py`; use successor versions, never overwrite previously handed-off ZIPs. Independent actual-host acceptance belongs to tests/context_clients. No service restarts or native edits.
