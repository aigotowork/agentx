### Scoped worker stop for reset

Clients requested `relay::worker::stop_relay_worker_client(&Client) -> Result<(), String>` for the actual reset router cutover, retaining the originating scope and generation. Selected structure before implementation: `worker.rs` retains lifecycle and publishes a worker owner sidecar next to the backward-compatible numeric `relay.pid`; private `worker_stop.rs` owns scoped lock/owner validation, process shutdown and exact native cleanup. The sidecar binds PID and observed OS incarnation at publication. Stop holds the existing scoped spawn lock, validates the supplied Client before effects, observes the captured owner, rechecks it immediately before each TERM/KILL, and confirms positive original exit or known PID reuse before cleanup. Unknown/empty ownership, malformed records, permission/observation failure, a replaced file/owner, unconfirmed termination or lost native cleanup reply return an error. No ambient Client, managed DB or database-daemon shutdown is permitted. Legacy numeric-only live workers are observable but cannot authorize unsafe signals without retained identity; positive exit still permits stale-file cleanup.

| State / case | Required effect and outcome |
| --- | --- |
| No recorded worker, native generation valid | Clear only Relay runtime through the same Client; no process signal |
| Known recorded worker, exact current OS incarnation | Request TERM once, poll up to 5 s, then revalidate before optional KILL and confirm exit within 1 s |
| Positive exit / two known different incarnations | Never signal the current occupant; clear only the captured stale owner |
| Unknown incarnation / malformed or inconsistent PID-owner files | Fail without signal, native clear or file deletion |
| Owner or pidfile replaced during stop | Fail without clearing successor state/files |
| Native generation stale / transport unavailable before stop | Fail before host signal/file mutation; never reacquire |
| Native cleanup reply lost after confirmed process exit | Return error and retain local evidence; never claim reset or no effect |
