## Native method correspondence correction — derivative released

Controller receiving found a real requirement gap: sourceIds plus a source-bound label did not reference actual method values, so a renamed/removed native method could leave the design apparently bound. Decision: add the smallest actual typed method binding, retaining the established authoring WeakMap isolation pattern and existing SchemaHandle vocabulary. No AST importer, native dispatcher or runtime wrapper is added. `bindNativeMethod<I,O>(NativeMethodSpec<I,O>): NativeMethodHandle<I,O>` binds the actual native function/prototype value to exact imported input/output SchemaHandles using NoInfer. The compiler checks registration, exact input reference, owner and duplicate method ownership. Missing real binding downgrades a source-linked operation to declared with `UNBOUND_NATIVE_METHOD`; forged/foreign, wrong input or owner handles are errors. Source-bound rules remain correspondence claims, independently of method handles.
