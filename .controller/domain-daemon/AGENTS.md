## Shared principles

- The user authorized design and implementation of the complete AgentX domain/client-daemon direction. Establish source-owned Rust contracts and a visible module skeleton before filling non-trivial behavior. Domain owners decide invariant/transaction semantics; the architecture owner resolves cross-domain contract conflicts.
- Native types and callable contracts are authoritative for Rust-owned capabilities. Selected protocol schemas and clients derive from them; never create independently editable copies. CLI syntax/presentation and external Provider protocols retain their own owners.
- Keep one binary with separate client/daemon entries. Scope database ownership by canonical AgentX data directory. Final production clients, hooks, PTY/stdio hosts, plugins, TUI and applicable relay workers cannot open the managed database or fall back to it after IPC failure.
- Keep client/session identity and effective launch environment explicit. A shared daemon's environment cannot select another client's identity, project or Provider session. Preserve participant incarnation, execution, attachment and receipt fences.
- Distinguish durable message acceptance, claim, external input, exact receipt and completed agent work. Timeout or a lost response is not proof that an external effect did not occur. Reuse existing guarantees before adding new mechanisms.
- AgentX and native Providers retain separate responsibilities. Preserve supported multi-provider behavior. Do not recreate a normal PATH Codex wrapper or substitute a user-installed binary.
- Keep the solution proportional: module-oriented boundaries first, no automatic package-per-domain, microservices, universal bus, event sourcing, DI framework or generic SQL/argv RPC as the final service API.
- Tests/probes use disposable data directories and fixed local fixtures. Do not point source-built clients/daemons at `.agentx`, the default home database, credentials or live user services. Use AgentX for team coordination; keep product test fixtures in their own disposable scopes.
- Each owner authors meaningful cases. The integration owner executes necessary Cargo/Node/build checks and records their scope; workers do not run overlapping broad builds. A bounded isolated external-protocol probe needs a named question and evidence.
- Do not overwrite another owner's changes or commit/reset/stash/push the shared tree. Coordinate an actual shared export/manifest edit before writing. Source owners update their module guide and contract links; do not leave discovery dependent on chat history.
- Record ambiguity, design friction and unresolved behavior in the owning Task/feedback. Report usable contracts, actionable blockers and completion through AgentX to the assigned participant; ordinary progress stays in the Task. Workers may communicate directly with sibling owners about real dependencies and may not spawn further Agents.

## Collaboration protocol

1. Read your Task and restore the exact owned capability, retained behavior, consumers, output locations and upstream conditions. Report acceptance through AgentX with your actual identity and any real missing prerequisite. Handoff requires an explicit source-ownership release.
2. Investigate the current implementation immediately within your scope. Publish a concise source-linked model, interface needs and risks; never implement against guessed sibling methods.
3. Architecture publishes native contract/skeleton and a source ownership handoff. A usable contract releases consumer implementation while providers proceed; unrelated open questions are not universal barriers.
4. Implement within the declared owner. Coordinate an actual overlap directly; update the contract/model before crossing a responsibility boundary to patch a symptom.
5. Hand domain-authored cases to integration. Report completion with callable source, evidence/limits, model/guide changes and resource release. Use AgentX messages/events for completion and finish your turn when waiting for a reply; do not poll, sleep or hold the parent turn open with no useful work.
