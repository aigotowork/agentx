## Model decisions and next condition

Keep the existing generated Management adapter and immutable scoped handles. Exact current and stopped Agents share `prepareTranscript` / `requestTranscript` and `launchRelations`; Transcript yields a bounded excerpt with explicit availability, separate from AgentX events, and native provides no Transcript continuation. Direct provenance has its own subject-bound cursor, historical creation identity and a separate nullable navigation observation; a stopped target comes from the native stopped reference, never a name lookup. A prepared command retains its original scope, kind, request ID, target and inputs; `scope.operation(prepared)` is observation only and validates status and compatible result. Address-only observation and legacy message submission remain compatible. Refuse mismatched results without interpreting them as rejection or permission to resend.

Route lifecycle by applicable exact reference, workspace launch by adopted workspace and current role selector, and attachment/mailbox/directory/activity by selected scope. Retain `members()` as the old global projection and add a separate native member page when available. Reject name-based launch discovery, implicit command replay, inferred historical role adoption, unscoped cursor reuse, and a new transport or operation registry. The native prerequisite Task owns the new membership/launch facts; their generated artifacts need a coordinated handoff. First executable contract releases Space, then complete the existing-native batch while native integration proceeds separately.
