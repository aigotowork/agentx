## Composition decision

The decisive question is whether someone can trace a known workspace to an exact Agent, distinguish Role catalog and adoption, then recover the original receipt with the map still available as context. One portable Layout hosts four views: Core Relationships, Management Context, Work & Evidence and Receipt Path. The Object Inspector is shared, with Attributes, Methods, Sources and relationship jumps. Search uses the same object selection; neighbor focus highlights without changing graph geometry. Narrow layouts keep readable map scale in a scroll pane and place the same inspector underneath. The receipt lens distinguishes caller knowledge from native journal state and uses an illustrative, fixed branch selection with no runtime calls. The visual method is [Signal Engraving](../../../.docs/object-atlas/visual-philosophy.md).


## Delivered workbench

The [portable HTML](../../../.docs/object-atlas/index.html) and [static PNG plate](../../../.docs/object-atlas/companion.png) are live on the existing [Atlas-only LAN preview](http://192.168.2.178:18987/); both responses were byte-compared to the delivered files. The [entry guide](../../../.docs/object-atlas/README.md) records offline use. Signal Engraving is expressed in three paper lanes, registration marks, directional edges, a folded object geometry, and a single yellow selected field. The still uses the same core SVG composition and adds its own print typography and legend.

| Layout / Block | Components and interaction |
| --- | --- |
| AtlasWorkbench / RelationshipCanvas | View navigation changes the three mapped clusters or selects ReceiptLens. Object tiles retain position as selection and neighbor emphasis change. Narrow view provides horizontal scroll, three zone buttons and a jump to the inspector. Overview resets the selection, view, emphasis and lens state. |
| ObjectInspector | Shared attributes, methods, source tabs, Current/Stopped toggle and typed relationship jumps. Sources show a repo-relative path, symbol and line; copying falls back to a selectable text field. No repo path is served by the Atlas preview. |
| GlobalSearch | Modal query by name, fields, methods or concept. Empty and no-match states, arrows and Enter, Escape to dismiss; a result selects its visible graph node and focuses it. |
| ReceiptLens | Four caller-evidence scenarios: reply loss, reply received, explicit refusal and local observation stopped. The original receipt address and distinct native statuses remain inspectable. The selected scenario and step drive highlighting and the same object inspector. Scenarios are fixed explanatory data, not simulated effects or accepted native executions. |

All selected content is embedded in index.html; there is no stored session, fetched fixture or service call. Reload restores the overview. Motion is limited to immediate state changes; no timed effects require a reduced-motion alternative. The 21 object entries and 68 source locations are curated, not a complete DTO or method registry. The [SDK evidence owner](../../typescript-domain-sdk/implementation.delivery.md#accepted-first-slice-outcome) holds the independently accepted first slice and adoption limits. This Atlas establishes no SDK publication, installed/live adoption, production Provider effects or native Workspace-filtered paging.
