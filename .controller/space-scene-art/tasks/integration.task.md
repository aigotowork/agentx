Diagnostics use the same placement functions with the last presented frame. No alternate Canvas, motion sampler or asset-owned interactions.
- **Cases:** Six exact current actors in one busy office; working, available and attention cues agree with the list; click/touch/keyboard open the same history and hold the draft across scene/list; close returns to the actor and preserves zoom across resize. The Annex has an actual modeled threshold and no cast. Pause and reduced motion preserve identity and settle the same frame. Diagnostic SVG boxes and Canvas PNG correspond to the presented frame; décor exposes no actions. Offline Studio makes no `/api` calls; configured Studio uses the existing SDK scope, workspace and exact history reads.
