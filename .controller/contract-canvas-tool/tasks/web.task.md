## Design handoff

[First Web paths over the AgentX domain SDK](../../../.docs/web-product-design/domain-sdk-scenarios.md) is the maintained design, linked from the [Web design index](../../../.docs/web-product-design/README.md). Space binds a focused Office/List roster, exact AgentX Messages reader and page-local draft, with a scene projection, typed selection intent and a single shared Canvas/DOM frame. Management binds an independent workspace inspection surface with today's Roles, bounded observed members and exact saved adoption. The design names the receiving Web seams and future acceptance cases and references the [independent SDK evidence](../../typescript-domain-sdk/tasks/integration.task.md#independent-outcome).

Source walkthrough findings: the Web bootstrap currently supplies a listener URL but no independently trusted `expectedScope`; the first implementation therefore takes an explicit configured pair from its host. Workspace pages are client projections of a global feed; full membership enumeration remains native/SDK follow-up. Exact Messages history is forward-only; the selected path labels its continuation accordingly. Native writes and receipt migration are separate from these read/draft scenarios. The respective owners and the implications for UI behavior are recorded in the design.
