## Authored candidate: operator model and selected scope

The operator alternates between an exact Agent identity, a relevant message passage and a draft. Two panes can belong to different targets; the active selection is not authority for a visible peer’s reads or writes. The fixed frame therefore owns identity (including current/stopped distinction), channel, search and pane controls; the scroll body owns records and the forward boundary; the footer owns deliberate send, attachments, receipt recovery and bounded editor size. The page controller owns each exact draft, including metadata and editor preference; shared layout remembers each exact channel’s visible record and position. The SDK consumer owns requests and lease cancellation. Provider Transcript remains an explicit separate operation.
