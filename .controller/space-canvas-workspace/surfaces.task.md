## Surface design

The compact reader keeps a short identity row (avatar, title, role and state), with two neighboring disclosures for provenance and instance details/actions. Below it are the two record channels, the scrolling record stream, and the persistent composer. Use existing Space type and palette; tighten spacing and remove redundant source chrome before reducing type. Preserve record bodies, tool disclosures, code and copy actions. The window owner supplies actions to the optional `workspaceControls` slot beside the channel buttons. Dropping the separate title bar removes the duplicate identity. Send keeps its visible label and sizes to its contents.

Relations stay next to the subject as a bounded in-pane disclosure. The former footer panel hid provenance on long streams and started reads before the user needed them; a separate route would interrupt comparison. Legacy single-reader placement remains available. Only the selected exact pane can sync the routed Agent facts disclosure. Auxiliary disclosures and transient send errors are pane-local. Workspace scroll restoration uses the exact ID and channel, including the all-offices reader; legacy scroll behavior remains unchanged.

Keep Create in the native modal with profile, optional title and task visible. Put the prefilled work directory under its own disclosure with the actual value visible when collapsed. Always-visible directory editing gave path input as much space as the task; a wizard would add a step to a four-field form. Native submission and original-operation reconciliation remain authoritative.
