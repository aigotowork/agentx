The [approved plan](../../.codex/attachments/27d79c69-f37d-45ad-b726-1914349d0e24/approved-plan.md) is authoritative. Keep the journal and exact instance bounds in native storage, instance typed cursors in the SDK, cache and live scheduling in Space's read controller, semantic viewport restore in the reader, and CSS sizing/tokens in UIUX. Do not add a second message store or new action journal. The latest read captures a bounded pre-read event high water; older pages use an exclusive event boundary and never update the live cursor. Missing capability selects the existing forward path.

Shared native/Space contract: descriptor marker `supports_message_history?: boolean`; HTTP `GET /api/v1/agents/{name}/message-history` with the existing generation and exact reference parameters, optional `before` and `limit`; response `{generation, messages, next_before: string|null, live_after: string|null}`. SDK `Agent.messageHistory({before?,limit?}, options?)` returns `{agent, messages, nextBefore: MessageHistoryCursor|null, liveAfter: MessageCursor|null}`. History cursor kind is `message-history` and contains `agent` and `position`. Use scope descriptor capability in Space, not a thrown 404 as capability detection.

Launch creator and Fork source have different owners. Creation provenance already records the launching actor. The additive `agent_creation_forks` table records the exact source used by native reservation when it is tracked: either current incarnation or stopped event. It belongs to the new creation and is preserved through resume aliases. Older and untracked Provider sessions have no source fact. The relations response adds optional `fork_source`; the SDK exposes `forkSource` separately from `upstream`. Keep the source informational when it is no longer an actionable current reference. The original operation receipt alone authorizes opening the new exact conversation.

Controller owns fixture, integration, docs and the LAN preview transition. Preview is synthetic; native proof uses disposable state and never changes the installed binary or existing AgentX run services. Prior LAN baseline is systemd transient service agentx-space-conversation-lan-preview.service, serving .artifacts/space-canvas-workspace/experience-r3 using workspace.fixture.mjs with long mode. Freeze actual script before changing it. Prior user stopped heavy scale/large-data experiments: use finite sparse tests rather than re-running the 750k load harness.

## Accepted verification

The controller froze the running preview's [previous unit and fixture](../../.artifacts/space-conversation-workbench/rollback/baseline.unit) before editing. The opt-in `workbench` dataset supplies medium/long Chinese records with code and TXT attachments, bounded relation pages, and exact simulated Fork receipts. Other modes retain legacy reading. [Space r5 build](../../.artifacts/space-conversation-workbench/candidate-r5/build.log), [UIUX validation](../../.artifacts/space-conversation-workbench/candidate-r1/uiux-check.log), and [older-service browser compatibility](../../.artifacts/space-conversation-workbench/candidate-r4/legacy-browser.log) passed.

[Native composition](../../.artifacts/space-conversation-workbench/native-composed-r1/browser-report.json) passed against the [frozen debug executable](../../.artifacts/space-conversation-workbench/native/candidate.sha256) and Space r3. The [runner](native_acceptance.py) used a disposable native daemon and local generated-hook Qoder substitute, seeded 47 messages in its private journal, verified the public SDK in Node, and opened the frozen Space bundle on the daemon origin with real HTTP. The SDK observed 20 recent, 20 older and 7 remaining records, with the original oldest first endpoint intact. Chromium reached latest on entry, scrolled for an older page, and submitted exactly one Fork. The native result showed a separate external creator and fenced Fork source; explicit opening preserved the original draft. The [manifest](../../.artifacts/space-conversation-workbench/native-composed-r1/manifest.json) records the immutable candidate and clean shutdown. No paid or real Provider was contacted.

The authoritative export left all 28 pre-existing HTTP path definitions unchanged. The [native task](native.task.md) links 25 passing SDK tests, nine passing targeted Rust tests, and the bounded seek plans. The [three migration cases](../../.artifacts/space-conversation-workbench/native/fork-migration.log) also passed. Unit cases cover the WAL snapshot during append and backfill, byte caps, refusal to report a false empty page at the raw scan cap, same-name current/stopped bounds, and generation/old daemon isolation. No large data load or full test suite was run.

The [independent evaluation](evaluation.task.md) selected its counterexamples before implementation inspection and compared 1440×900 dual, 1280×800 single, 375×812 touch emulation and 1280×540 short desktop. It retains actual body line and complete-record counts. On the same aligned Chinese/code/attachment record, counts were 1/0/0/0 complete messages and 10/8/9/5 visible body lines (dual per pane). The tests verified idle parked readers, return to drafts and offsets, keyboard and touch relations, exact Fork and same-request recovery after an intentionally lost reply. R4 fixed actionable retry and Escape: the sampled retry preserved record 101 at +35 px before and after prepend. R5 fixed the late mobile scroll rounding issue; the 375px short-page probe kept the same record at +83 px through prepend and the next paint. The [independent R5 spot check](evaluation.task.md) and [full R5 focused replay](../../.artifacts/space-conversation-workbench/frontend-focused-r5-final/focused.json) passed. Browser evidence is sampled Linux Chromium; the mobile viewport and IME are emulated. It does not establish unprompted discoverability by real users or real Provider interoperability.
