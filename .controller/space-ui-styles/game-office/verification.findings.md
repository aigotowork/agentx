# Illustrated office browser findings

All six independent Chromium cases passed against the Controller's exact r2 builds and the read-only Studio fixture. Chromium first attempted both assigned preview URLs and received `ERR_EMPTY_RESPONSE` in this session. The run then fulfilled requests from `/tmp/agentx-game-office-r2` and `/tmp/agentx-game-office-design-r2` and served the existing Studio fixture's GET payloads at the same URLs. This evidence covers the actual Space and Design Canvas browser builds, their SDK request shapes, and Canvas presentation. Direct LAN access, other browsers and live Agent behavior remain outside this result. Playwright MCP was unavailable under the session approval policy; the runner used local Chromium 156.0.8078.4 through Playwright.

All product API requests were same-origin GETs. The runner recorded no mutation attempts, failed API/art responses, or page errors. The initial run's still-state observer treated any redraw as animation; it saw one frame after pausing Inkpost and did not retain that frame's input revision. The final observer checks the clock and revisions, requires a continuous quiet window, and distinguishes any input redraw from a frame produced without new input. The final measurement had zero extra input redraws in those windows. Both r1 runs and the final r2 run are retained: [initial r1 report](../../../.artifacts/space-ui-styles/game-office-zilima-r1/report.json), [passing r1 report](../../../.artifacts/space-ui-styles/game-office-zilima-r1-final/report.json), [final r2 report](../../../.artifacts/space-ui-styles/game-office-zilima-r2/report.json).

The final r2 screenshots show Windward's updated wood floor, camera rails themed to each world, and Jadecourt's warmer lantern tint. No issue blocked the tested reader or return path. At 390 px the status filter visibly truncates 全部状态 beside 联系目录. At 1440 px the reader's camera adjustment keeps `@mora` in view but crops off the left edge of the room, including the lantern and part of the neighboring actor area. The three Design Canvas cards also show a full-width, unthemed white status control that breaks the dark toolbar's visual grouping in Inkpost and Jadecourt. These are screenshot observations; interaction timing was sampled in headless Chromium, with emulated touch and reduced motion.
