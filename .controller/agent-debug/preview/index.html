问题建议真实替代与代价
谁持有 socket？每个准确 Agent 的长驻 AgentX 宿主；daemon 与操作者访问同地址。daemon 代理：断 daemon 失诊断；Provider 持有：共享后端与单 Agent 生命周期不匹配。
必须保持长连接吗？daemon 可复用可重连会话；操作者短请求 / 事件订阅。断线后重读原生邮箱。每次短调用也能保正确性；常驻会话减少握手、便于观察链路，但增加重连与流控。
维护结果保留多久？仅扫描 / 只读探测 / 重连；保留期内同 ID 同参数复用，过期 NotRetained / Unknown，不自动重发。原稿要求宿主时钟却无供给，现已移除。永久去重需额外持久权威；当前维护不承担消息去重。
怎样开始实施？S1 真实 PTY 闭环；S2 shared bridge 与其余维护；S3 其余受支持宿主完成后才声称全覆盖。一次交付所有模式与三类维护，反馈更晚；阶段边界不缩减最终“每个启动 Agent”目标。
