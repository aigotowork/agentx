# Canvas-design source and scope

This directory carries the complete `canvas-design` Skill and font resources
adopted from the consuming DancingAI project. The supplied license identifies
Anthropic, PBC., 2026 and Apache-2.0; see [LICENSE.txt](LICENSE.txt). Font-specific
OFL notices remain alongside the font files in `canvas-fonts/`. The upstream
revision was not recorded in the imported material; no exact upstream version
or fresh upstream verification is claimed. The supplied Skill, license and fonts
are retained unchanged.

Read [SKILL.md](SKILL.md) for static artwork production. Its output-format and
minimal-text directions apply to that asset only. Interactive products retain
their navigation, accessibility, explanatory content and actual consumer duties.
This resource does not install a renderer, image generator or Agent integration.
