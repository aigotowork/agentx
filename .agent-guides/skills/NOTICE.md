# Harness Skill sources

Harness-authored Skills and the image preparation method are maintained in this guidance tree. Their delivery is authorized for the consuming project; no public open-source license is declared for that original material. This notice does not grant third-party redistribution rights.

The portable release's Skill catalog records exact source paths, adaptations, dependencies and file digests. Cloudflare retains its own Apache-2.0 license and provenance beside its unchanged snapshot. The shadcn Skill contains its upstream MIT license. Native programs used by these Skills have their own distributions and licenses; they are not included merely by copying a Skill.

Canvas-design retains its supplied Anthropic Apache-2.0 license and individual
font OFL notices in `canvas-design/`. Codebase-memory's imported native Skill
snapshot retains its MIT license and version provenance beside the adapted
interface notes. Neither resource's inclusion installs the corresponding runtime.
