# Technical explanation method

Enter through [AGENTS.md](AGENTS.md). The method connects a reader's engineering question to an evidence-based explanation whose main form can be text, diagrams, an experiment, a runnable work or video.

The working objects are a reader decision, claim with conditions, evidence, explanatory model, observation/action sequence, material, artifact version and published representation. A source recording and an edited video have different identities. A teaching model and production behavior have different evidence. A human-readable fallback and a machine text projection have different acceptance conditions.

Planning methods select the question, evidence and form. Production methods preserve those relationships in models, controls, runnable works and media. Publication methods review the whole experience and verify the actual host. The [worked example](examples/contended-resource.md) connects those responsibilities without assuming a particular platform.

Use the consumer's existing content source, native schema, media home, component owner and Task records. A local adapter can locate those contracts and state project-specific differences; it should link the shared method instead of copying it. This domain supplies no renderer, CMS plugin, production media, activated Skill or deployment command. Its [basis](refs/method-basis.md) distinguishes authored decisions from reference material and observed effectiveness.
