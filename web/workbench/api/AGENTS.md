# Workbench public SDK integration

Native [Service declarations](../../../src/collaboration/service.rs) and [browser contract](../../../.docs/collaboration-workbench/browser-api.md) remain authoritative. `native.ts` is a compatibility import entry of aliases from public `WorkbenchTypes`; derive from the emitted SDK contract rather than hand-authoring DTOs. Native Service → OpenAPI → package generation is the maintained source chain.

`client.ts` owns only page connection/read lifetime and delegates named connection/read/apply operations, integer validation, errors and retained full unknown command inputs to `@agentx/client`. SDK `WorkOutcomeUnknown` is exposed as the existing `OutcomeUnknown` import; its `.input` holds the original ApplyCall. Closing cancels local reads, never submitted work. UI owns selected state/drafts, original command lookup and explicit exact-input replay. Use `?workbenchUrl=URL` only for explicitly separate hosting; default is the embedded listener, independent of Management/Observation. Build the public package first as documented in [usage](../../../packages/agentx-client/README.md#web-consumers). Execution belongs the [adoption integration Task](../../../.controller/web-sdk-adoption/integration.task.md).
