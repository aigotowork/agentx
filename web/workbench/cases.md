# Workbench authored cases

Status: authored, unexecuted by Web. Independent acceptance owns execution and evidence. Canonical scenarios and SVG states remain in [S1–S5](../../.docs/collaboration-workbench/experience.md#唯一场景源与四张图) and [the thirteen-scene contracts](../../.docs/collaboration-workbench/interface-details.md); the rows below identify actual implementation paths and meaningful failure boundaries, not another scenario source.

| Case / source | Setup and action | Required observation |

The Node-authored cases isolate identity, byte validation, local draft cloning, finite pending metadata, exact evidence addressing and explicit-fact filtering. Browser cases deliberately cover command/navigation overlap and native effects, which a pure selector test cannot establish. No general fake backend or snapshot-only suite is selected.
