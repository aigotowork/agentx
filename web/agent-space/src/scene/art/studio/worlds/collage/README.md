# Collage · 彩纸事务所

A high contrast editorial office assembled from cut paper: primary blue, signal red, warm yellow, teal accents, off-white stock and charcoal registration shadows. Shapes are deliberately stepped and slightly offset, with broad color blocks carrying depth instead of the outlined, two-ink print language used by Newsprint.

The room is organized as one composition. Blue windows and red frames lock the rear wall; a yellow-and-blue rug anchors the lounge; the red desk and archive cabinet create a strong work-to-storage diagonal; the mailbox and teal cat mark the entry. Shadows sit below the planes and keep actor feet, badges and the doorway readable at small scale.

The cast uses four distinct silhouettes at the fixed 64 × 72 display size: a broad yellow-helmet maker with a blue press tool, an angular blue-haired designer carrying a yellow proof, a tall keeper in a yellow coat with a red folio, and a lean teal scout with a red courier bag. `glyph-work`, `glyph-available`, `glyph-attention` and `glyph-select` use compact tool, speech, warning and under-foot selection shapes.

Palette: paper `#FFF6E5`, charcoal `#1E2430`, primary blue `#2D5BFF`, signal red `#EF4B3E`, warm yellow `#FFD34D`, teal `#159C8B`. All 25 SVGs are self-contained, editable vectors with no scripts, fonts, raster embeds or external references. The 23 Studio IDs preserve the exact dimensions and anchors in `studio-art.ts`; `scene-vista.svg` is 800 × 450 and `scene-lantern.svg` is 64 × 62.

Open [`proof.html`](proof.html) for a local whole-office composition and native-size cast strip. It uses only local SVG masters and no runtime facts. The pack is ready for the Studio loader; renderer, CSS, SDK and previews remain untouched.
