# Agent Lobby artwork and motion provenance

The bots production office directly imports the original Agent Lobby pixel art,
animation frames and pure walking path calculation from the preserved source
snapshot. The browser renderer, product projection, interaction and camera are
bots-owned adaptations. No Lobby host registration, RPC writer or design fixture
is imported.

Upstream: https://github.com/linhmh8/agent-lobby.git

are preserved in `repos/lobby` without inventing an attribution. See
`repos/lobby-source.json` for provenance and hashes, and
`repos/lobby/client/pixel/README.md` for original artwork documentation.
