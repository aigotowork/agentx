Bots modifications include canonical response isolation, source-sequence tool keys, task snapshots scoped to runs, replacement of changed live entries with equal sequence coverage, expanded searchable text, and a separate Bots-owned work projection. The initial local Bots source was imported from `oliexe/paseo-bots` commit `e9d444e772ecd2da3d4b89d47e9b12f5d6c62cb0`; see [the import record](../../upstream/source.json).

The content-completeness refinement additionally retains plans and Claude task tools, preserves successfully parsed task status and empty/deleted snapshots, supplies bounded fallback records, supports incremental long-text disclosure, and compacts existing turn/header presentation. Existing PlanCard gains search-forced disclosure; existing detail cards display fixed-SDK supplementary fields. These changes do not claim a complete port of Paseo's renderer.

`client/chat/stream/projection.ts`, the new process/tool/task React Native presentation, and local disclosure rules are authored for Bots. The comparison of assistant-ui, AI Elements and Ant Design X informs design choices; this slice does not copy their source or install their runtime packages. No third-party plugin, terminal engine, fonts, images or other upstream third-party assets are copied by this slice.

New `AgentConversation`, `ConversationInfo`, `MessageImage`, `timeline-observation`, `stream/content`, `ContentFallback`, `ReadOnlyRecord` and completeness fixtures are authored for Bots. They use installed public SDK/RN contracts; they do not copy private host contexts, source registries, plugin handlers or an image/terminal engine. The tiny embedded fixture PNG is test data, not an imported upstream product asset.
