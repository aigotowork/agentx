# Independent browser acceptance

Owned finite execution for [verification Task](../../../.controller/agent-space/verification.md), with scenarios owned by [implementation](../../../.controller/agent-space/implementation.md#acceptance-scenarios-for-the-independent-executor). These scripts operate an already served artifact; they never build, start, stop or mutate a user preview.

`browser-acceptance.mjs` binds scene/reader/draft/disclosure/filter/archive/narrow scenarios and records DOM outcomes, geometry, network, runtime console and screenshots. `selection-camera.mjs` binds the user-reported camera issue and related select/close/mode/resize/panorama paths, measuring actual canvas scale and fixed landmarks after animation frames. Moving actors and the responsive cabinet position cannot independently establish camera restoration across resize; the room origin is the stable resize landmark. On narrow screens close the reader before accessing the underlying panorama control.

Use existing installed Playwright and Chrome paths declared in the scripts. Set `AGENT_SPACE_URL` to the owned static origin and `AGENT_SPACE_EVIDENCE` to disposable output. `AGENT_SPACE_CASES` selects affected browser case names by regular expression. Camera assertions require `AGENT_SPACE_ASSERT_CAMERA=1`; `AGENT_SPACE_WIDTHS=390,320` selects affected widths. Do not routinely rerun completed checks: the Task records which inputs and cases were actually executed.

Retained evidence is under [2026-11-15](evidence/2026-11-15/). Initial failed attempts include corrected executor assumptions and the two independently reproduced source defects; final records retain actual outcomes rather than rewriting history. `final-camera-desktop-and-partial-narrow.json` includes the completed desktop trace and an interrupted narrow trace (underlying panorama was covered by the reader). `final-camera-narrow.json` is the completed narrow continuation using close→panorama. Full disposable captures remain in `/tmp/agent-space-evidence-mofe-20261115/` while available. Evidence does not establish real API delivery, durable storage, physical-mobile keyboard behavior or arbitrary browser compatibility.


For the [unified Domain SDK Space entry](../../../.controller/space-domain-sdk/unified-entry.task.md), `node --experimental-transform-types --test web/agent-space/tests/domain-office.test.mjs` exercises the actual `LiveSpace` consumer and public SDK against disposable responses: refused scope, sparse workspace continuation and retry, stopped/current discriminator isolation, late read cancellation, legacy roster and compatible receipt recovery, and confirmed generation reset. Existing route, context, relation and scene tests cover their owning guarantees. Independently built browser evidence and exact selectors belong to the Space Task.

For [local direct calls](../../../.controller/direct-calls/local.task.md), run `node web/agent-space/tests/direct-calls.browser.mjs BUILD EVIDENCE` against a fresh `/space/` build. It serves disposable loopback fixtures with separately missing member/history capabilities, checks the corresponding UI, and records the original exact send receipt and single describe across browser refreshes.
