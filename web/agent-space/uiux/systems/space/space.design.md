# AgentX Space design direction

Space is a compact working room for finding an exact Agent instance, reading its separate records, and deliberately sending or retaining a draft. The complete composition keeps office navigation and resource identity visible beside the existing pixel Canvas or conversation reader. The reader owns history scrolling and the footer owns composer reachability; narrow layouts collapse navigation to a local return while preserving the page-owned selection and draft.

The visual language extends the existing warm paper, ink, green action, thin border, pixel avatar, and compact type rhythm. Foundation values, typography, spacing and semantic aliases are owned by `styles/foundation.css`; scene-local art and window roles remain in `styles/office.css`; state meaning comes from text, disabled semantics, `aria-pressed`, and actionable feedback. `SpaceTheme` scopes tokens and selectors to the consumer; UIUX chrome remains outside that scope. Width adaptation follows the actual `space-shell` container.

Presentation is a three-value contract in `components/presentation.ts`: `classic` preserves the original styles, while `folio` and `signal` select the experimental semantic token maps in `styles/candidates.css`. `parseSpaceStyle` accepts only registered IDs and leaves absent or unknown values for the product's preference policy to resolve. `SpaceStyleSwitch` renders the same controlled choices in full or compact headers. Theme changes affect presentation only; the product retains selection, drafts, route, SDK supply and effect authority.

The primary feedback contract is truthful delivery: accepted local note appends clear its draft; an Agent send clears only after a native `Succeeded` operation and only when the exact draft revision still matches the sent value. Unknown or failed outcomes retain the draft and attachments for recovery. Accepted/Running operations retain the draft until the same receipt resolves. In-memory completion handlers survive reader unmount and selection changes; scope/generation changes retire them. Scenes model results locally and never call native effects.
