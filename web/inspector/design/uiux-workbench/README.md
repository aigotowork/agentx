# Agent Inspector · 组装式工作台

Slug：`uiux-workbench`

这组三板把工作台的默认行为定为“先看整体、再局部选中”：中央画布先呈现真实 Inspector 的组合界面，颜色、文字、控件、布局与图标样本贴近组合而存在。左侧第二列是紧凑的图层/组合树；资源库是按需打开的浮层，加入资源后直接形成画布实例。

## 画板

- `assembly-desktop.html`：1440px 桌面整体默认态。可切一级导航、搜索图层、打开资源库、添加资源、显示 Layout 槽位、打开文档 Sheet。
- `selection-inspector.html`：1440px 整体画布中的局部选中态。表格行被选中，右侧检查器可切属性／变量／事件；整体组合仍保留在视野内。
- `mobile-layout.html`：390px 窄屏局部检查器与 Layout 编辑态。画布优先，检查器滑入，返回保留选择；编辑预览显示槽名和尺寸，运行预览隐藏占位边界。

## 交互路径

1. 默认整体画布 → 在图层树点选 `活动表格` → 右侧检查器显示局部属性 → `Esc` 或返回维持整体上下文。
2. `资源库` 或 `⌘K / Ctrl+K` → 搜索／点选 `状态徽章` → 加入画布 → 可再次选择的新实例出现在当前组合。
3. `属性 / 变量 / 事件` 只改变同一检查器的局部信息层，不离开画布；`ⓘ` 打开单一文档 Sheet，关闭后焦点回到原按钮。
4. `显示槽位` 或 `编辑预览` → 看到 `main / aside` 槽边界、名称与尺寸；切回 `运行预览` 后占位边界消失。
5. 320px 下按 `检查器` → 侧滑局部检查器 → `返回画布`，选择、画布与滚动上下文保留；页面不产生横向溢出。

视觉基线是浅色细致中性层级：`#f4f6f8` 工作区、`#fff` 内容面、`#dbe2e8` 细边、`#17212b` 文字，`#2563eb` 受控强调，成功使用 `#0f9f6e`。常用间距为 4/8/12/16px，控件高度 28/32px，阴影只用于浮层与工作区边界。

页面行为是本地模拟，未连接产品数据或业务命令；它只用于传达工作台结构与交互路径。

## 实际验证

原生 `design_create` 注册三张画板，`design_read` 已完整读取；当前没有用户批注。未修改用户批注、tweaks 值或画板位置，所有 HTML 最后加载 Canvas 管理的 `tweaks.css`。

使用仓库现有 Playwright Chromium 从 `file://` 加载，完成 27 项定向走查：整体与局部选择同步、属性／变量／事件、文档焦点约束与关闭返回、资源搜索和可见实例、快捷搜索、图层筛选与收起、聚焦返回、编辑／运行槽位隐藏、重置、320px 触摸与 Tooltip。1440、390、320px 均无整页或中央画布横向溢出，无 JavaScript 运行错误。记录见 [verification.json](verification.json)。

1440px 一屏内同时保留 3 个指标、3 个 Agent 的状态和事件、24h 趋势与观察覆盖、颜色／文字／控件／布局样本，以及当前对象检查器；资源加入和文档分别经一次局部披露到达。320px 默认保持组合、3 指标和活动列表，检查器经一次打开到达，返回保留选择和工作区位置；不将滑入层内的控件计为默认同屏可见。
