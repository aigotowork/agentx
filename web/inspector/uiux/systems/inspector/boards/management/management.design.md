# 管理场景 · 整体搭配

先看完整管理界面的导航、搜索、列表、状态和详情如何共同工作，再选中局部调整同一实例的参数。场景只组合 Inspector 正式组件；命名 CSS 拥有此组合的空间关系，不复制组件实现。

固定设计样例为4条记录，其中68与420来自已接受设计，总量488；缺失值为未提供，不产生逐日趋势。搜索、选择、备注、主题和浮层是本地交互，不连接业务命令。停止与未知保留语义，不推断成功。

scene.parts 把局部名称、资源和controls关联起来。检查图标调用宿主 inspect，检查器仅显示该局部参数；场景继续挂载。可恢复的参数由args承载，输入通过updateArgs回传，不把临时事件日志或业务效果当作保存结果。

该组合为设计实验，正式采用需进入组件源码与产品验收，不能由方案保存或构建通过自动推断。
