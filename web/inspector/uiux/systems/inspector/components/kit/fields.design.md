# 输入与搜索

受控输入转发编辑意图，主题切换保留输入实例。

## 使用与设计理由

使用正式 `TextField`，通过 `inspector.native.ts` 消费。输入、选择、禁用与忙碌由源码契约决定；场景只组合真实组件和明确本地状态。视觉通过语义主题解析，不重建组件树。

## 状态、事件与边界

状态和事件见相邻 `fields.resource.json`；可执行场景见 `fields.scenes.tsx`，props 以真实源类型为准。操作由用户触发，事件记录不表示业务命令成功。系统减少动态优先，浮层归公共 OverlayBoundary；不创建页面局部提示定位。

## 验证

编译与目录检查只确认契约／路径；浏览器交互验证禁用、输入身份、主题及适配。不把设计场景作为原生 App 或所有业务页面的验收。
