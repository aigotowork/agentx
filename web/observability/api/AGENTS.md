# Passive Observation SDK boundary

The [native adapter contract](../../../.docs/observability/browser-api.md) remains authoritative. `native.ts` aliases public `ObservationTypes`; generic conveniences project existing emitted component fields and never maintain another DTO schema. Historical derive.py is retained for provenance, not the current SDK generation path. Native Service → emitted OpenAPI → public SDK owns exact wire/schema codecs, full native result/error unions, bounded in-flight reads and one EventsRead guard.

`ObservationApi.connect()` selects its explicit `?observationUrl=URL` or current embedded listener, reads scope and delegates all passive calls to `createObservationClient`. The wrapper owns the page's connection only. `close()` cancels local reads and never acquires/starts/stops a daemon. Keep integer references/frontiers as bigint and native unknown/gap/withheld/LocalFailure distinctions intact. No storage, worker or implicit polling/retry is supplied. Page state owns existing orchestration. Vite bundles the public SDK into hashed finite assets; `/api/` stays reserved for native HTTP. See [setup and current support](../../../packages/agentx-client/README.md#web-consumers) and [integration evidence owner](../../../.controller/web-sdk-adoption/integration.task.md).
